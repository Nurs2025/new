# Английские слова

Тренажёр английских слов: показывается слово по-русски, нужно написать его по-английски.

- 504 самых нужных слова: семья, тело и здоровье, еда, дом, одежда, город и транспорт, природа, животные, время, цвета, частые прилагательные и глаголы, работа и учёба, полезные слова
- Если вариантов перевода несколько (mother/mom/mum, flat/apartment, colour/color), засчитывается любой
- Слово считается выученным после 3 правильных ответов подряд
- Озвучка произношения
- Меню ☰: список всех слов с поиском, удаление ненужных слов и возврат удалённых
- Прогресс сохраняется в браузере на устройстве

Всё приложение находится в одном файле, `index.html`. Опубликовано через GitHub Pages: https://nurs2025.github.io/new/
