# Английские слова

Тренажёр английских слов: показывается слово по-русски, нужно написать его по-английски.

- Около 210 готовых слов (деловой английский) и раздел «Мои слова», куда можно добавить свои
- Слово считается выученным после 3 правильных ответов подряд
- Озвучка произношения
- Прогресс и свои слова сохраняются в браузере на устройстве

Всё приложение находится в одном файле, `index.html`. Его можно открыть в браузере или опубликовать через GitHub Pages.
