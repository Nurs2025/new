# Английские глаголы

Тренажёр неправильных глаголов английского языка: показывается слово по-русски, нужно написать все три формы.

- 96 самых употребительных неправильных глаголов (go — went — gone, take — took — taken…)
- Три поля: 1 форма (Infinitive), 2 форма (Past Simple), 3 форма (Past Participle). Поля подсвечиваются зелёным или красным
- Если вариантов два (learnt/learned, was/were, got/gotten), засчитывается любой из них
- Слово считается выученным после 3 правильных ответов подряд
- Озвучка всех трёх форм
- Меню ☰: добавить своё слово (глагол с тремя формами или обычное слово с одной), найти и удалить ненужные слова
- Прогресс и свои слова сохраняются в браузере на устройстве

Всё приложение находится в одном файле, `index.html`. Опубликовано через GitHub Pages: https://nurs2025.github.io/new/
