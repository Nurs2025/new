# Урок 1. Первая программа, переменные, ввод и вывод

## 1. Вывод на экран: print
```python
print("Привет, мир!")
```
`print` выводит текст. Текст пишут в кавычках.

## 2. Переменные
Переменная — это «коробка» с именем, в которой лежит значение.
```python
name = "Анна"
age = 20
print(name)
print(age)
```

## 3. Типы данных
- `"Анна"` — строка (`str`)
- `20` — целое число (`int`)
- `3.5` — дробное число (`float`)

## 4. Арифметика
```python
print(2 + 3)    # 5
print(10 - 4)   # 6
print(3 * 4)    # 12
print(7 / 2)    # 3.5
print(7 // 2)   # 3  (целая часть)
print(7 % 2)    # 1  (остаток)
print(2 ** 3)   # 8  (степень)
```

## 5. Ввод данных: input
```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```
`input` всегда возвращает **строку**. Чтобы получить число:
```python
age = int(input("Сколько тебе лет? "))
print("Через год тебе будет", age + 1)
```

## 6. Комментарии
Всё после `#` Python игнорирует — это заметки для себя.
